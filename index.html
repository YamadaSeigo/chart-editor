譜面エディタ

編集する譜面を選んでください。各エディタのヘッダー左上からも切り替えられます。

TECH Chart Editor

1

銃で狙い撃つ TECH アクションの譜面（NotesRecord）。osu! 風のプレイフィールドで位置と時刻を編集します。

  • 単発 / 長撃ち / 同時撃ち / 連射
  • 時刻は秒（Offset を引いたゲーム内時刻）

POWER Chart Editor

2

Joy-Con で殴る POWER アクションの譜面（PowerChart）。左手・右手の2レーンを上から流れるノーツで編集します。

  • ジャブ / アッパー / フック / 連打
  • 時刻は拍（beat / rushBeats）
