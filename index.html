編集する譜面を選んでください。各エディタのヘッダー左上からも切り替えられます。はじめての人は 使い方 を読んでください。

TECH Chart Editor

1

銃で狙い撃つ TECH アクションの譜面（NotesRecord）。osu! 風のプレイフィールドで位置と時刻を編集します。

  • 単発 / 長撃ち / 同時撃ち / 連射
  • 時刻は秒（Offset を引いたゲーム内時刻）

POWER Chart Editor

2

Joy-Con で殴る POWER アクションの譜面（PowerChart）。左手・右手の2レーンを上から流れるノーツで編集します。

  • ジャブ / アッパー / フック / 連打
  • 時刻は拍（beat / rushBeats）

SHIFT / SYNC Editor

3

曲ごとの Time Shift（担当ディスプレイの入れ替え）と Sync Action（二人で腕を上げる）の拍（ShiftSyncChart）。難易度に関係なく1曲に1つ。

  • Time Shift の拍 / Sync Action の拍と制限時間
  • 時刻は拍（SongData の BPM で秒に換算）

SONG Editor

4

ドライブにある難易度ごとの譜面（POWER / TECH × 4）と SHIFT / SYNC、音源を選んで1曲（SongData）にまとめます。

  • 曲名・アーティスト・色・BPM・Offset
  • Unity の Drive Chart Sync で SongData に取り込む
