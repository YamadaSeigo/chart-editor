はじめに

MS2026 Chart Editor は、ゲーム「MS2026」の譜面（ノーツ）をブラウザで作り、チームで共有するためのツールです。 作った譜面は Google ドライブに保存され、Unity に取り込むとそのままゲームで使えます。

ツールは、トップページの 譜面ボード（誰が何を作っているかの一覧）と、4つの エディタ でできています。

TECH Chart Editor銃で撃つ TECH 側の譜面。難易度ごとに1つ POWER Chart EditorJoy-Con で殴る POWER 側の譜面。難易度ごとに1つ SHIFT / SYNC EditorTime Shift（担当の入れ替え）と Sync Action（二人で腕を上げる）のタイミング。曲に1つ SONG Editor上の3つと音源を選んで、1曲（SongData）にまとめる。曲に1つ
ℹ1曲を完成させるには、POWER 4つ（Easy・Normal・Hard・Extra）＋ TECH 4つ ＋ SHIFT/SYNC 1つ ＋ SONG 1つ = 10個 を作ります。譜面ボードではこの10個を1枚のカードにまとめて表示します。
💡ブラウザは Microsoft Edge か Google Chrome を使ってください（ファイルの保存に必要な機能が Firefox・Safari にはありません）。

作業の流れ

1曲がゲームに入るまでの流れです。番号順に進めれば迷いません。

1音源を置く曲の音声ファイルを Google ドライブの音源フォルダに入れる
ファイル名の最後に BPM（例 iris_190.wav）
2ボードに登録トップページの「音源」から「ボードに追加」。10個のマスができる
3担当を決めて作るマスをクリック →「自分」で担当に →「エディタで開く」
4保存して提出エディタで「☁ ドライブに保存」→「✓ 作業完了」で確認待ちに
5確認して完成確認した人がボードで状態を完成にする
6SONG にまとめるSONG Editor で譜面・SHIFT/SYNC・音源を選んで保存
7Unity に取り込むTools > SyncShift > Drive Chart Sync で取り込む

最初の準備

  1. ページを開く
    チームで共有されている URL（GitHub Pages）を開きます。Windows なら、リポジトリにある MS2026 Chart Editor.lnk などのショートカットからアプリのように開けます（Edge のアプリモード）。
  2. 名前を入れる
    最初に「あなたの名前を入力してください」と出ます。ボードの担当や「保存した人」として記録されるので、チームで同じ書き方にしてください（下に出る候補から選べます）。あとで右上の 👤 から変えられます。
  3. （管理者だけ）ボードの設定
    譜面ボードは Google スプレッドシート ＋ Apps Script で動いています。最初の設定や Apps Script を更新したときの手順は BOARD_SETUP.md を見てください。ふつうに使う人は何もしなくて大丈夫です。

譜面ボード

トップページの下半分が譜面ボードです。「どの曲の、どの譜面を、誰が作っていて、今どうなっているか」をチーム全員で同じ画面で見られます。内容は30秒ごとに自動で最新になります。

マスの色＝状態です。

未着手：まだ誰も手を付けていない作成中：作っている途中確認待ち：作り終わって、確認してほしい完成：確認も終わった
マスの中意味
1行目の右（☁ …）Google ドライブに保存されている中身。48 ノーツ などの数が出ていれば保存済み、☁ 未保存 ならまだドライブにない。SHIFT/SYNC は TS＝Time Shift の数・SA＝Sync Action の数
2行目担当の人。自分が担当のマスには ★
3行目期限（過ぎていると赤）か、メモ
黄色い枠いま誰かがエディタで開いている（「○○ が編集中」）。同じ譜面を同時に編集しないように気を付けてください
点線の「＋ 追加」まだボードに登録されていない。押すと登録される

1 曲名の行には、全体の進み具合（色の帯）と「完成した数 / 全部の数」、まだ終わっていないものの中で一番近い期限が出ます。

操作

絞り込み

  • 検索欄：曲名・担当・アセット名で絞り込み
  • 曲：未完成の曲だけ / 完成した曲だけ / すべて
  • 強調：選んだ状態のマスだけを目立たせて、ほかを薄くする（例：「確認待ち」で、確認しないといけないものが一目で分かる）
  • 自分の担当：自分が担当しているものがある曲だけにする

ボードとドライブのチェック

ボードの上に「⚠ ボードとドライブの食い違い」と出ることがあります。「詳しく見る」で内容とボタンが出ます。

  • 完成・確認待ちなのにドライブにない：保存を忘れていないか確認
  • ドライブに保存済みなのに未着手：「作成中にする」で直せる
  • ボード外：ドライブにあるのにボードにないファイル。「ボードに追加」するか、いらなければ「🗑 ゴミ箱へ」（ゴミ箱フォルダへ移すだけなので元に戻せます）

音源の一覧

ボードの下に、Google ドライブの音源フォルダの曲が並びます。

  • ▶ で試聴できます
  • まだボードにない曲は「未登録」。ボードに追加 で、上にチェックしてあるもの（POWER・TECH × 難易度、SHIFT/SYNC、SONG）がまとめて登録されます
  • 曲名は音源のファイル名（拡張子なし）になります。曲名と音源のファイル名が同じだと、エディタで開いたときに音源が自動で読み込まれます

エディタ共通

4つのエディタは、上のバー（ヘッダー）の作りがだいたい同じです。

☁ ドライブに保存 ☁ 開く ♪ ドライブの音源チームの Google ドライブに保存・ドライブから開く・ドライブの音源を読み込む。ふだんはこちらを使います

TECHTECH Chart Editor

銃（Wii リモコン）で撃つ TECH 側の譜面を作ります。上のタイムラインで「いつ」、真ん中のプレイフィールドで「どこに」出すかを決めます（osu! の編集画面に似ています）。時刻は秒です。

ノーツの種類

キーツール置き方
1選択ノーツを選んで動かす・消す
2単発撃ち（Shot）プレイフィールドをクリック
3長撃ち（Hold）クリックしたまま終点までドラッグ
4同時撃ち（Sync）クリックしたまま相方の位置までドラッグ
5連射（Rush）クリックで置き、タイムラインで末尾をドラッグして長さを決める

作り方

  1. ボードからマスを開く（または「名前」をボードのアセット名にする）。音源が自動で読み込まれなければ「♪ ドライブの音源」で選ぶ
  2. ヘッダーの BPM と Offset を曲に合わせる（グリッドが拍に合う）
  3. 再生して、置きたいところで止め、ツールを選んでプレイフィールドをクリック。置く時刻はスナップ（拍の刻み）に合わせられます
  4. 右のパネルで、ノーツごとの大きさ・出現までの時間・連射の回数などを細かく変えられる（複数選んでまとめて変更も可）
  5. できたら「☁ ドライブに保存」→「✓ 作業完了」

便利なキー

← → / ホイールスナップ単位で移動（Shift で1拍単位）
Gプレイフィールドのグリッドに吸着
Ctrl+C / Vコピー / 今の時刻に貼り付け
Ctrl+H / J選んだノーツを左右 / 上下に反転
F / A選んだノーツに表示を合わせる / 全体を表示
ℹノーツが重なっているときは、選んでいるノーツをもう一度クリックすると下のノーツが選ばれます。くわしくはエディタ右上の ? を見てください。

POWERPOWER Chart Editor

Joy-Con で殴る POWER 側の譜面を作ります。ゲームと同じく左手・右手の2レーンがあり、ノーツは上から流れてきて、判定の拍ちょうどに下の的に着きます。時刻は拍です。

ノーツの種類

キーツール見た目・動き
1選択ノーツを選んで動かす・消す
2ジャブ（Jab）点。まっすぐ打つ
3アッパー（Upper）上向きの矢印
4フック（Hook）内向きの矢印。左レーンに置けば左フック、右レーンなら右フック
5連打（Rush）長い帯。末尾をドラッグして長さを決める。左右両方のレーンに置くのが基本

作り方

  1. ボードからマスを開く。音源・BPM・Offset を合わせる
  2. ツールを選んで、プレビューかタイムラインの左右どちらかのレーンをクリック。クリックしたレーンの手で置かれる
  3. 左のツール欄の「配置先」を L+R にすると左右同時に置ける（Z 左 / C 右 / X 両方）
  4. ノーツを反対のレーンへドラッグすると手が変わる
  5. できたら「☁ ドライブに保存」→「✓ 作業完了」

SHIFT/SYNCSHIFT / SYNC Editor

曲の中の2つの演出のタイミングを決めます。難易度に関係なく1曲に1つです。時刻は拍です。

演出ゲームで起きること
Time ShiftPOWER と TECH の担当ディスプレイが入れ替わる。入れ替わる4秒前から「TIME CHANGE」とカウントダウンが出て、その間はノーツが出ない（プレイヤーが移動する時間）
Sync Action二人が同時に片腕を上げて保つと成功。制限時間（何も入れなければ10秒）のうちに成功しないと失敗。その間はノーツが出ない

画面

タイムライン上から「音源の波形」「Time Shift の行」「Sync Action の行」。
Time Shift の線の手前の帯が準備時間、Sync Action の帯の長さが制限時間
右のパネル拍・制限時間を数字で直す一覧と、チェック（重なりなどの警告）、プレビューの設定
再生バー再生・メトロノーム・合図の音

作り方

  1. ボードから開く（曲の音源が自動で読み込まれる）。ヘッダーの BPM と Offset を曲に合わせる
  2. 入れ替えたい拍で、Time Shift の行をクリック（または再生中に T）
  3. 腕を上げてほしい拍で、Sync Action の行をクリック（または Y）。帯の右端をドラッグで制限時間を変える
  4. 再生して確認。ゲームと同じ案内（TIME CHANGE 3、SYNC ACTION 残り…）が右上に出て、合図の音も鳴る
  5. 右のチェックに警告が出ていないか見る（Sync Action が Time Shift の準備時間と重なっている、など）
  6. 「☁ ドライブに保存」。ボードの SHIFT/SYNC のマスで状態を「確認待ち」にする
ドラッグ移動
右クリック / Delete削除
← →選んだものを1スナップ動かす
Shift+クリック複数選択
ホイール / Ctrl+ホイール横スクロール / 拡大縮小
ℹBPM と Offset は拍と秒の換算に使うだけで、保存されるファイルには入りません（曲の BPM は SONG Editor で決めます）。

SONGSONG Editor

ドライブにある譜面（POWER 4つ・TECH 4つ）・SHIFT/SYNC・音源を選んで、1曲にまとめます。これが Unity の SongData になり、楽曲セレクトに並びます。

作り方

  1. ボードの SONG のマスから開く（または「＋ 新しい曲」）。左には保存済みの曲が並ぶ
  2. 音源を選ぶ。ファイル名から曲名・BPM・アセット名が自動で入る（例 Future Stage _150.wav → BPM 150）。▶ で試聴
  3. 曲名・アーティスト・セレクトで使う色・Offset を入れる
  4. ⚡ 曲名から自動で選ぶ を押すと、ボードの登録に合わせて8マスと SHIFT/SYNC が埋まる。違っていればプルダウンで選び直す
  5. 各マスの下に、ボードの状態とドライブのノーツ数が出る。下のチェックに「まだ完成していない」「選ばれていない」などが出ていないか確認
  6. 「☁ ドライブに保存」（Ctrl+S）
ℹSONG Editor が保存するのは「どの譜面を使うか」の名前の一覧（.json）です。中の譜面を直したいときは、それぞれのエディタで直して保存すれば、SONG を作り直す必要はありません。

Unity に取り込む

ドライブに保存したものは、Unity のメニュー Tools > SyncShift > Drive Chart Sync から取り込みます。

  1. ウィンドウを開くと、ドライブのファイルが並ぶ（TECH・POWER・SHIFTSYNC・SONG）
  2. 「更新あり」は 取り込む、「プロジェクトにない」は 作る。まとめてなら「更新をすべて取り込む」「ないものも作って取り込む」
  3. SONG を取り込むと、使っている譜面・SHIFT/SYNC がプロジェクトになければ先に取り込んでから、SongData を作る（音源は同じ名前の AudioClip を探す）
  4. できた SongData を楽曲セレクト（SongSelect）に並べる
💡「自動で取り込む」をオンにすると、ウィンドウを閉じていても数秒おきにドライブを確認して、更新された譜面を自動で取り込みます（再生中も）。
ℹすでにプロジェクトにある同じ名前のアセットは中身だけ書き換えるので、ほかからの参照は切れません。

困ったとき

こんなときこうする
「ドライブに保存できませんでした」通信を確認してもう一度。「パートが不正です」などが出るときは、Apps Script が古いので管理者に更新してもらう（BOARD_SETUP.md）
「上書きしますか？」と出たほかの人が先に保存しています。キャンセルして「☁ 開く」で中身を確かめ、話し合ってから保存
ボードに「編集中」と出ないエディタの「名前」がボードのアセット名と同じか確認。名前を入れていない（👤 未設定）と出ません
「編集中」が消えないエディタを閉じれば消えます。強制終了したときは3分で自動で消えます
音源が自動で読み込まれないボードの曲名と音源のファイル名（拡張子なし）が同じか確認。エディタの「♪ ドライブの音源」から手で選べます
ノーツが音とずれるBPM と Offset を確認。Offset は「譜面と音のズレ」（秒）。SONG Editor の Offset がゲームで使われます
タブを閉じてしまった同じブラウザで開き直せば、最後の内容が自動で戻ります
いらない譜面を消したいボードの詳細の「🗑 削除」でボードから消す。ドライブのファイルは、ボードのチェックの「🗑 ゴミ箱へ」でゴミ箱フォルダへ（元に戻せます）

用語集

アセット名ファイルの名前（拡張子なし）。例 TechChart_iris190_Hard。ボード・エディタの「名前」・ドライブ・Unity で同じ名前を使って結び付ける
BPM1分あたりの拍の数。曲の速さ
Offset譜面と音のズレを直す秒数
スナップノーツを置ける拍の細かさ（1/4 なら4分の1拍ごと）
.assetUnity のデータファイル。TECH は NotesRecord、POWER は PowerChart、SHIFT/SYNC は ShiftSyncChart
SongData1曲ぶんのデータ。曲・BPM・難易度ごとの譜面・SHIFT/SYNC をまとめたもの
難易度Easy・Normal・Hard・Extra。ゲーム中、プレイの正確さに合わせて自動で切り替わる
