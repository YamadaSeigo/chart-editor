SHIFT / SYNC Editor

📖 ボードと全エディタの使い方（はじめての人向け）を別のタブで開く

曲ごとの Time Shift（POWER と TECH の担当ディスプレイの入れ替え）と Sync Action（二人で片腕を上げて保つ）の拍を編集し、 Unity の ShiftSyncChart（Assets/WorkSpace/Scripts/InGame/SyncShift/ShiftSyncChart.cs）の .asset として保存します。 難易度に関係なく1曲に1つで、SongData の「Time Shift / Sync Action」に割り当てます。

タイムライン

  • Time Shift の行をクリックで追加。線の手前の帯は準備時間（案内とカウントダウンが出て、ノーツが出ない時間）。
  • Sync Action の行をクリックで追加。帯の長さは制限時間。帯の右端をドラッグすると制限時間を変えられます（0 にすると初期値）。
  • 上のルーラー・波形をクリック／ドラッグで再生位置を移動。ホイールで横スクロール、Ctrl+ホイールで拡大縮小。
  • 右クリックで削除。Shift+クリックで複数選択。

キー

Space再生 / 停止
T再生位置（スナップ）に Time Shift を追加
Y再生位置（スナップ）に Sync Action を追加
Delete選択を削除
← →選択を1スナップ動かす（選択がなければ再生位置）
Ctrl+Z / Ctrl+Y元に戻す / やり直し
Ctrl+S / Ctrl+Shift+S / Ctrl+O保存 / 名前を付けて保存 / 開く

保存

  • BPM と Offset は拍と秒の換算・音源合わせのためだけに使い、.asset には入りません（曲の BPM は SongData.bpm）。
  • 保存先は Assets/WorkSpace/ScriptableObjects/Songs/ など。既存の .asset を開いて上書きすれば .meta の GUID は変わらないので参照は切れません。
  • ファイル名と m_Name は同じにします（名前を付けて保存すると自動で合わせます）。
