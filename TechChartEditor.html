TECH Chart Editor — 使い方

osu! の Compose 画面風の譜面エディタです。上のタイムラインで時間、中央のプレイフィールドで位置を編集します。座標系・判定値は TechNotesManager（フィールド既定 17×9.5 ※ヘッダーで変更可、当たり半径 1.0）に合わせています。

配置

  • ツール 2〜5 を選んでプレイフィールドをクリック → 現在時刻（スナップ済み）に配置
  • Hold / Sync はクリックしたままドラッグで 終点 / 相方の位置 を決定
  • タイムラインの空き部分をクリックしても配置できます（位置は直前のノーツ）
  • タイムラインで Hold / Rush の末尾をドラッグ → 長さを変更
  • ノーツが重なっているときは下のノーツが一回り大きく表示されます。選択中のノーツをもう一度クリックすると下のノーツが選択されます（繰り返すと順番に切り替わります）

Unity への取り込み

  • 「名前を付けて保存」で保存先フォルダとファイル名を選ぶと NotesRecord 形式の .asset（または .json）を保存します。Assets/WorkSpace/ScriptableObjects/ に保存すれば TechNotesManager.record に割り当てられます。
  • 保存先は記憶され、次からは「保存」（Ctrl+S）で同じファイルに上書きされます。アプリを再起動しても保存先は残ります（初回だけ書き込みの許可を求められます）。
  • 「開く」で読み込んだ .asset / .json もそのまま保存先になるので、Unity 側のアセットを直接編集→上書きできます。
  • .asset の m_Name は保存したファイル名に合わせます。既存アセットを上書きしても .meta の GUID は変わらないので参照は切れません。
  • フィールドの大きさは譜面データ（.asset）には含まれません。ゲーム側の TechNotesManager の「プレイフィールドの大きさ」と合わせてください。
  • spawnTime / hitTime は TechTestChartGenerator と同じ式で計算します：spawnTime = max(0.1, 判定時刻 − Approach)、hitTime = min(Approach, 判定時刻 − 0.1)。
  • 時刻は「楽曲の Offset を引いたゲーム内時刻」です。BPM を変えてもノーツの秒数は変わりません。
