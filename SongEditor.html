保存される中身（JSON）と Unity での使い方

ドライブの曲は Unity の SongData そのものではなく、どの譜面を使うかをアセット名で持つ JSON です。 Unity の Tools > SyncShift > Drive Chart Sync で取り込むと、同じ名前の PowerChart / NotesRecord / ShiftSyncChart（なければドライブから先に取り込む）と AudioClip を探して SongData を作ります（既にあれば中身を更新。GUID は変わらないので SongSelect などからの参照はそのまま）。
