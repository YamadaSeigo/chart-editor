POWER Chart Editor — 使い方

POWER（ボクシング）側の譜面 PowerChart を編集するエディタです。ゲームと同じく 左手・右手の2レーン に分かれていて、ノーツは上から流れてきて判定の拍ちょうどに下の的に着きます。レーンの位置・色・印は PowerNotesDrawer の既定値に合わせています（ジャブ：点、アッパー：上矢印、フック：内向きの矢印、連打：長い帯）。

配置

  • ツール 2〜5 を選んで、プレビューかタイムラインの 左右どちらかのレーン をクリック → そのレーンの手で配置（プレビューは現在の拍、タイムラインはクリックした拍）
  • フックは置いたレーンで決まります（左レーン＝左フック、右レーン＝右フック）
  • 左のツールの「配置先」を L+R にすると左右両方のレーンに同時に置きます（ゲームの連打は左右両方に置くのが基本）
  • タイムラインでノーツを反対のレーンへドラッグ → 手を変更。連打の末尾をドラッグ → 長さを変更
  • 「打ち込み」をオンにして再生し、キーを押すとその瞬間に一番近いスナップ位置へ置きます（R で切り替え）
    左手 A ジャブ / S アッパー / D フック、右手 J ジャブ / K アッパー / L フック、2〜5 は「配置先」のレーンへ

Unity への取り込み

  • 「名前を付けて保存」で PowerChart 形式の .asset（または .json）を保存します。Assets/WorkSpace/ScriptableObjects/（難易度別は Difficulty/PowerChart_Hard.asset など）に保存すれば SongData.powerCharts / PowerNotesManager に割り当てられます。
  • 保存先は記憶され、次からは「保存」（Ctrl+S）で同じファイルに上書きされます。「開く」で読み込んだ .asset もそのまま保存先になるので、既存アセットを直接編集できます（.meta の GUID は変わらないので参照は切れません）。
  • 古い譜面を開くと PowerChart.Normalize と同じ変換をします：廃止したドロップ（type 2）は除外、手が Any のノーツは直前と反対の手（最初は左）、Any の連打は左右両方のレーンに分けます。保存すると変換後の形で書き出されます。
  • 譜面は 拍 で保存されます（beat / rushBeats）。BPM・Offset・Approach は譜面には含まれないので、SongData と PowerNotesManager の値と合わせてください。
  • 連打の必要ヒット数は PowerNotesManager の既定値（1レーンあたり 5 発/秒）で表示しています。
